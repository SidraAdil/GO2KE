# Adding-gene-sets-to-Key-Events

This repository contains the R scripts used to systematically assign Gene Ontology (GO) biological process gene sets to Key Events (KEs) in the AOP-Wiki. The workflow supports transcriptomics-based quantification of Adverse Outcome Pathways (AOPs) by generating KE-associated gene sets. We demonstrate its application through a liver toxicity case study using the Open TG-GATEs primary human hepatocyte (PHH) transcriptomics dataset.

---

All R scripts are located in the `scripts/` directory.

## Scripts

### 1. GO-Based Gene Set Assignment

**Script**

`GO_gene_mapping.R`

**Description**

Retrieves genes associated with Gene Ontology (GO) biological process terms and assigns gene sets to both pre-annotated and newly annotated Key Events. Gene identifiers are standardized to Ensembl IDs to facilitate downstream transcriptomics analyses.

---

### 2. Liver AOP Network Construction

#### `AOP_selection.R`

**Description**

Retrieves liver-associated Adverse Outcome Pathways (AOPs) from the AOP-Wiki RDF SPARQL endpoint using predefined liver-related keywords. Following manual curation of the retrieved AOPs, the script extracts the corresponding Key Events (KEs) and Key Event Relationships (KERs) required for network construction.

**Outputs**

- `selected_liver_aops.tsv`
- `kes.tsv`
- `ker.tsv`

---

#### `AOP_network_preparation.R`

**Description**

Prepares the liver AOP network by generating node and edge tables and integrating GO-based KE gene sets. The script produces network files for both **State I** (pre-annotated KEs) and **State III** (improved pre-annotated plus newly annotated KEs), including annotation status and KE gene set information.

**Outputs**

- `nodes.tsv`
- `edges.tsv`
- `state_I_nodes.tsv`
- `state_III_nodes.tsv`

---

#### `AOP_network_visualization.R`

**Description**

Generates and visualizes the liver AOP network in Cytoscape using the prepared node and edge tables. Nodes are styled according to annotation status, node size is scaled by the associated KE gene set size, and network statistics are calculated to identify highly connected (hub) KEs.

**Outputs**

- Cytoscape session (`.cys`)
- `top_10_hub_nodes.tsv`

---

### 3. Case Study: Pesticide-Induced Liver Toxicity

#### `data_processing_tg_gates.R`

**Description**

Processes the Open TG-GATEs primary human hepatocyte (PHH) transcriptomics dataset by performing differential gene expression analysis using the **limma** package. Differential expression profiles are generated by comparing treated samples with controls for each dose level and exposure duration.

**Outputs**

- Differential expression tables (`.tsv`) for each compound, dose level, and time point
- `pheno_info.tsv`

---

#### `nes_State_III.R`

**Description**

Computes Key Event (KE) perturbation scores using single-sample Gene Set Enrichment Analysis (ssGSEA) and evaluates pesticide-induced perturbations in the enhanced liver AOP network (State III). The script identifies significantly perturbed KEs and generates the results used for downstream analyses and visualizations.

## Input Data

The manually curated Gene Ontology (GO) biological process annotations for previously unannotated Key Events are publicly available on Zenodo.

**DOI:** https://doi.org/10.5281/zenodo.21264953

The dataset contains organ-specific KE–GO mappings for:

- Brain
- Kidney
- Liver
- Lung

These files serve as input for `GO_gene_mapping.R`.
